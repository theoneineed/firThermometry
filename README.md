# firThermometry
This repo holds the codebase developed to read and analyze the fluorescence data from spectrophotometer to be used for FIR optical thermometry.




Tips for reproduction

In terminal from the root folder for this project...

1. Create a virtual environment

    python -m venv .venv || python3 -m venv .venv

2. Activate the environment

    Operating System  |  Terminal / Shell  |  Activation Command \\
    macOS / Linux  | bash / zsh | source .venv/bin/activate \\
    Windows | Command Prompt (cmd)  |  .venv\Scripts\activate.bat \\
    Windows | PowerShell | .venv\Scripts\Activate.ps1 \\

3. Install required packages

    pip install -r requirements.txt

4. To deactivate the environment

    deactivate
